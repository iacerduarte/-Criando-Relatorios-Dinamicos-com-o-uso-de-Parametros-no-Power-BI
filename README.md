# 📊 Criando Relatórios Dinâmicos com Parâmetros no Power BI

## 🚀 Sobre o Projeto
Este projeto tem como objetivo a construção de um **relatório dinâmico no Power BI**, utilizando **parâmetros de campos** para permitir maior interatividade e melhor experiência do usuário.

A proposta é evoluir um relatório previamente desenvolvido, aplicando conceitos de UX (User Experience), tornando a navegação mais intuitiva, analítica e orientada à tomada de decisão.

---

## 🎯 Objetivo
- Criar visuais dinâmicos utilizando parâmetros  
- Melhorar a experiência do usuário no relatório  
- Aplicar storytelling com dados  
- Consolidar um projeto de portfólio para área de dados  

---

## 🧠 Conceitos Aplicados
- Parâmetros de campos no Power BI  
- UX aplicado a dashboards  
- Storytelling com dados  
- Interatividade com botões e navegação  
- Padronização visual  

---

## 📌 Estrutura do Projeto

O relatório foi desenvolvido considerando duas abordagens principais:

### 🔹 1. Parâmetro por Categorias
Permite ao usuário alternar dinamicamente entre diferentes dimensões (ex: produto, região, segmento).

### 🔹 2. Parâmetro por Valores
Permite alternar métricas analisadas:
- Profit  
- Sales  
- Outras métricas relevantes  

---

## 🎨 Experiência do Usuário (UX)
O projeto segue boas práticas de UX:

- Layout limpo e padronizado  
- Navegação intuitiva  
- Uso de botões para alternância de visuais  
- Destaque para informações relevantes  
- Redução de poluição visual  

---

## 📖 Storytelling com Dados
Foi criada uma página que simula a apresentação para um cliente, com foco em:

- Contextualização dos dados  
- Insights claros  
- Fluxo lógico de análise  
- Tomada de decisão orientada
